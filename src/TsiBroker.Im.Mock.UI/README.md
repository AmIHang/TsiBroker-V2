# src/TsiBroker.Im.Mock.UI

Vue 3 console for `TsiBroker.Im.Mock` (the ISB test double): configure its response behaviour,
send messages, and inspect the message log. Shares design tokens/components and the
username/password cookie-auth pattern with [TsiBroker.Ui](../TsiBroker.Ui), the admin UI.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
